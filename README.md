# Financial Graphs

Animated Canvas visualizations of compounding interest.

## Live Demo

[▶ View](https://enfren.github.io/financial-graphs/)

## Currently Included

| Graph | Description |
|---|---|
| Daily Compounding | $100 @ 3.5% APY, day-by-day through 2028 (leap year), animated line reveal |

## Tech

- Pure vanilla JS + Canvas 2D — no libraries
- Single `index.html` file
- Real calendar iteration (handles leap years, month rollovers)
- `requestAnimationFrame` for smooth point-by-point animation
